Translations · மொழிபெயர்ப்பு

Each file has the Tamil label and its English. The language files also have a column for that language, filled with the current values. Fill the column in, then upload the file here.

1. Download a file

Each download includes the current values, so you can see what is already translated.

Download the combined file for all languages

2. Fill in the empty places

  • Type the translation in the column for your language. Keep numbers, times and the symbols (·, °, %) as they are.
  • Leave a field empty to show English for that label.
  • Keep panchangam terms in the form your community uses. If unsure, write the Tamil or English word in brackets.

3. Upload the filled file

An upload replaces the values of that language on this device. Empty fields show English. The Tamil → English file has no language column, so it is only for reference.

Sending it back

To share a finished language with everyone, send the filled file in a GitHub issue or pull request (see CONTRIBUTING.md).
