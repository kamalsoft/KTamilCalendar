Translations · மொழிபெயர்ப்பு

One file holds every language. Each line has the Tamil label, its English, and an empty place for Telugu, Malayalam, Kannada and Hindi.

1. Download the file

Download the template

2. Fill in the empty places

  • Type the translation in the te, ml, kn or hi field of each line.
  • Leave a field empty to keep English for that label.
  • Keep numbers, times and the symbols (·, °, %) as they are.
  • Keep panchangam terms in the form your community uses. If unsure, write the Tamil or English word in brackets.

3. Upload the filled file

The file is checked here and kept on this device. The app uses it for the languages you filled in.

Sending it back

To share a finished language with everyone, send the filled file in a GitHub issue or pull request (see CONTRIBUTING.md).
